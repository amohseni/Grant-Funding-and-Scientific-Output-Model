# data/ — the corrected parameter-sweep dataset

**→ Full schema and column meanings are in `../DATA_DICTIONARY.md`. Read that first.**

- 13 sweeps × 3 files each: `<sweep>_summary.rds` (cell-level, the main file), `<sweep>_raw.rds`
  (trial-level), `<sweep>_rawlong.rds` (per-round schedule).
- 172 parameter cells total, **200 trials per cell**.
- `plots/` — quick-look ggplots auto-generated by the runner (`_primary` / `_secondary` per sweep).
  For paper figures, prefer `../report/results_report.html` or build your own from the `.rds`.
- `run.log` — console log of the production run (per-sweep timing; ~30 min total).

Load anything with `readRDS("data/<file>.rds")` → returns a data.frame. No project/code setup needed.

**Provenance:** generated from the **fixed** planner (deterministic `ce_reweight`, M=400) by
`../validation/launch_manifest_fixed.R`. A superseded, buggy pre-fix run exists in the project root
at `sweep_results/T_run/` — **do not use it**; these files are the corrected version.

Quick sanity check that you've got the right data:
```r
s <- readRDS("data/horizon_growth_summary.rds")
# forward beats myopic everywhere, grows with epsilon; all fwd_vs_myo_PG_mean >= 0:
all(s$fwd_vs_myo_PG_mean >= -0.01)          # TRUE
max(s$fwd_vs_myo_PG_mean)                    # ~1.66 (eps=0.85, T=5)
```
