# for-claude: grant-funding paper working set

Home of the paper "Funding the capability-resource gap: a model of optimal science
funding" (Mohseni, DeDeo, Zollman). Moved here from the for-claude repo
(drafts/grant-funding/) on 2026-09-05 at Aydin's direction, to live beside the model
and sweep data it draws on. state.md is the project tracker; tex/ holds the paper
source and figures; a pointer remains at the old location. Claude sessions write here
via the device bridge when this folder is connected, and read results from ../docs and
../sweep_results.
